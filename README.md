En Français Ce dépôt contient le dossier de configuration EFI complet et fonctionnel pour installer macOS Sequoia (version 15) sur un ordinateur portable Lenovo IdeaPad 3 15ADA05. Le chargeur d'amorçage utilisé est OpenCore. L'intégralité des pilotes, des tables ACPI corrigées et des kexts nécessaires au bon fonctionnement du matériel y est incluse. Notez que macOS 26 (Tahoe) n'est pas pris en charge en raison de l'incompatibilité des pilotes graphiques intégrés AMD.Matériel pris en charge sous macOS 15 :Processeur et carte graphique intégrée (AMD Ryzen / Radeon Graphics via NootedRed).Gestion de l'énergie et niveau de batterie.Clavier et pavé tactile (I2C/PS2).Connexions audio, USB et stockage NVMe.Avant l'utilisation :Pensez à générer vos propres identifiants système uniques (SMBIOS) à l'aide de l'outil GenSMBIOS. Remplissez ensuite les champs MLB, SystemSerialNumber et SystemUUID dans le fichier config.plist avant de tenter de démarrer le système pour la première fois.

In English This repository provides a complete and functional EFI configuration folder for running macOS Sequoia (version 15) on a Lenovo IdeaPad 3 15ADA05 laptop. Built on the OpenCore bootloader, this setup includes all the necessary ACPI patches, drivers, and kexts required for a stable system. Note that macOS 26 (Tahoe) is strictly unsupported due to the lack of compatibility with integrated AMD graphics.Working hardware features on macOS 15:CPU and integrated GPU acceleration (AMD Ryzen / Radeon Graphics via NootedRed).Battery status and power management.Keyboard and trackpad input (I2C/PS2).Internal audio, USB mapping, and NVMe storage.Important note:You must generate your own unique SMBIOS values using GenSMBIOS. Make sure to populate the MLB, SystemSerialNumber, and SystemUUID keys inside the config.plist file before attempting to boot your machine.
